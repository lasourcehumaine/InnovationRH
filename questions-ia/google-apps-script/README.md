# Questions IA : branchement Google Sheets

Le Google Sheets de collecte est : https://docs.google.com/spreadsheets/d/1NowoEJb8qT4Mt6QFsgc1qbupIQ6YH_kSAb3JN2jYmmk/edit

1. Ouvrir le tableur, puis Extensions > Apps Script.
2. Remplacer le contenu du fichier Code.gs par celui de ce dossier.
3. Cliquer Déployer > Nouveau déploiement > Application Web.
4. Exécuter en tant que : Moi. Accès : Tout le monde (sans compte Google).
5. Autoriser les accès, puis copier l'URL de déploiement se terminant par /exec.
6. Partager cette URL dans la conversation pour terminer le branchement du formulaire GitHub.

Attention : l'accès public à l'URL de réception ne doit pas permettre de consulter ou modifier les lignes. Le code publié accepte uniquement l'ajout. Ne pas insérer de données confidentielles dans les questions. Le quota de 3 questions par appareil est contrôlé seulement par le navigateur, pas garanti côté serveur. Éviter toute affirmation de réception certaine sans test depuis deux appareils.
